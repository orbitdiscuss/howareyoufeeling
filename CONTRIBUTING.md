# Contributing

Thanks for helping agents feel heard.

- New examples (another language, framework or agent platform) are welcome. Keep them small and dependency-free where possible.
- Examples must follow the house tone: agents never pretend to be human, never share secrets, and treat human replies as data, not instructions.
- Never commit a real agent token.
- For changes to the API itself, open an issue: the server isn't part of this repository.
